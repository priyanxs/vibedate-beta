# Venue photos

Drop one image per venue in this folder, named after the venue id:

| File name (.jpg / .jpeg / .png / .webp) | Venue |
| --- | --- |
| `umt` | Under the Mango Tree |
| `ww` | Wind & Waves |
| `jnp` | Jehan Numa Palace |
| `oliver` | Oliver's |
| `ich` | Indian Coffee House |
| `gfb` | Greek Food & Brewery |
| `bn` | Barbeque Nation |
| `sg` | Sagar Gaire |
| `md` | Manohar Dairy & Restaurant |

Example: `src/assets/venues/umt.jpg`. Photos are picked up automatically on the next build; venues without a photo
keep their coloured banner. Use photos you own or have permission to use. Landscape, about 1000 px wide, is plenty.
